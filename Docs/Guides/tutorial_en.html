ShapeSync Tutorial Guide (tutorial_en.html)

This guide provides a step-by-step tutorial for ShapeSync—a 3D avatar fitting and body deformation middleware for Unity. Learn how to convert your avatar into a Figure, create fitting Outfits, and control Full Body Morphs (FBM) in real time.

1. Introduction

1.1 ShapeSync Overview

ShapeSync is a middleware for Unity designed to control 3D avatar outfit attachment and dynamic body deformation. It operates standalone with the Core Package (net.zgock-lab.shapesync) for Figure Builder, Mesh Utility, and DynamicBoneBlender without requiring external libraries like UniVRM.

  • Target Environment: Unity 6.0 LTS or later (Standard Rendering: Universal Render Pipeline / URP)
  • Core Package: net.zgock-lab.shapesync (Operates standalone without UniVRM)
  • VRM Companion: net.zgock-lab.shapesync.vrm (Optional ShapeSync VRM support package)

1.2 Core Concepts

Key concepts to understand when working with ShapeSync:

Concept Description
Figure The base character prefab serving as the foundation for fitting and body morphs. Holds the main SkinnedMeshRenderer, bone hierarchy, and deformation schemas.
Outfit Wearable assets such as clothing, hair, or accessories attached to a Figure. Automatically deforms and scales in sync with the Figure's body morphs.
FBM (Full Body Morph) A unified system integrating Mesh BlendShapes, Bindposes, and Humanoid Avatars to dynamically deform the character's entire body including mesh and bone scales/positions.

2. Quick Start (Running the Sample Scene)

Start by opening the bundled sample scene to experience real-time Full Body Morphing (FBM) and dynamic outfit attachment/detachment.

Step 1: Open the Sample Scene

  1. In the Unity Project window, navigate to and double-click Assets/Scenes/SampleScene.unity.

Step 2: Inspect Scene Components

Select [BasicFemale_ShapeSync] in the Hierarchy window and observe the Inspector panel.

The [BasicFemale_ShapeSync] GameObject contains two key ShapeSync runtime components:

  • DynamicBoneBlender: Controls FBM Weight morphing, bone scaling, and bindpose adjustments.
  • OutfitAttacher: Manages Outfit attach/detach operations and synchronizes FBM changes to attached Outfits.
Figure 1: Sample character [BasicFemale_ShapeSync] setup with DynamicBoneBlender and OutfitAttacher components

Step 3: Enter Play Mode & Test FBM (Body Morphing)

  1. Click the Play button at the top of the Unity Editor.
  2. Select [BasicFemale_ShapeSync] in the Hierarchy.
  3. In the Inspector, locate DynamicBoneBlender and drag the Target Weight slider (e.g., BasicGirl).
  4. Verify that the character's mesh and bone structure deform smoothly in real time.

Step 4: Test Outfit Attachment & Detachment

  1. While still in Play mode, locate Shirt_ShapeSyncOutfit.prefab in Assets/Models/.
  2. Drag and drop Shirt_ShapeSyncOutfit.prefab into the box labeled "Drop Outfit Prefab Here" inside the OutfitAttacher Inspector area.
  3. Observe that the shirt is attached to the character and follows the FBM body deformations seamlessly.
  4. The attached shirt will appear under Attached Outfits. Click the "Delete (Detach)" button next to the entry to detach it immediately.

3. Practical Guide 1: Creating a Figure Asset

Learn how to author a ShapeSync-compatible Figure asset from your custom 3D avatar model and verify real-time FBM deformation during a walk animation.

This tutorial uses a VRoid Studio exported .vrm file as the Unity input Prefab, requiring UniVRM to be installed beforehand. UniVRM is used exclusively for VRM import; the ShapeSync Core workflow (Mesh Utility / Figure Builder / FBM) does not require SHAPESYNC_USE_UNIVRM.

Prerequisites (Avatar Models & Animation Clips)

  • Base Figure (Base): Assets/Models/VRM/BasicFemale.vrm
  • FBM Target (Target): Assets/Models/VRM/BasicGirl.vrm (Topology-identical avatar with different body proportions)
  • Walk Animation: A Humanoid-compatible walk animation clip, such as the Universal Animation Library by Quaternius (CC0).

※ Always verify licensing terms (CC0, etc.) for source models and animations prior to production use.

Step 1: Merge Meshes with Mesh Utility (Preprocess)

If your source avatar consists of split SkinnedMeshRenderer components (Body, Face, Hair, etc.), merge them into a single renderer as a preprocessing step.

  1. Open Tools > zgock > ShapeSync > Mesh Utility from the top menu.
  2. Select the Mesh Assembly tab at the top of the window.
  3. Drag and drop Assets/Models/VRM/BasicFemale.vrm into the Root Object field.
  4. Click "Collect Skinned Mesh Renderers From Root" to gather child renderers into the list.
  5. Click "Generate Merged Prefab" to export the merged base prefab (saved under Assets/Models/Base/).
  6. Repeat the same Mesh Assembly process for the target avatar Assets/Models/VRM/BasicGirl.vrm.
Figure 2: Mesh Utility (Mesh Assembly tab) - Collecting renderers and generating merged prefabs

Step 2: Generate Figure Prefab with Figure Builder

Build the ShapeSync Figure asset using the merged mesh data.

  1. Open Tools > zgock > ShapeSync > Figure Builder from the menu.
  2. Assign the merged BasicFemale SkinnedMeshRenderer to Base Renderer.
  3. Click "Add Target" under the Target FBM Entries section.
  4. Assign the merged BasicGirl SkinnedMeshRenderer to the target entry and enter BasicGirl as the BlendName.
  5. Click "Generate BlendShape Prefab".
  6. A complete Figure Prefab with FBM BlendShapes, CharacterBoneRegistry, and runtime components (DynamicBoneBlender, OutfitAttacher) will be generated in Assets/Models/.
Figure 3: Assigning Base Renderer and Target FBM Entries in Figure Builder

Step 3: Scene Placement, Animation & Verification

  1. Place the generated Figure Prefab into the scene.
  2. Assign an Animator Controller with the walk animation clip to the Figure's Animator component.
  3. Enter Play mode.
  4. While the character is walking, drag the BasicGirl Weight slider in DynamicBoneBlender.
  5. Success Criterion: The body shape (mesh and bones) morphs smoothly and stably without breaking the walk animation execution.
Figure 4: Real-time FBM Weight modification verified during continuous walk animation playback

4. Practical Guide 2: Creating Outfit Assets

Extract clothing meshes from clothed avatar models to create ShapeSync Outfit assets that automatically deform alongside the Figure's FBM morphs.

Step 1: Extract Clothing with Mesh Utility (Separator)

Isolate and extract clothing sub-meshes into an independent Outfit prefab.

  1. Open Tools > zgock > ShapeSync > Mesh Utility.
  2. Select the Mesh Separation tab.
  3. Assign the clothed avatar's SkinnedMeshRenderer to Source Renderer.
  4. Check the material slots corresponding to clothing (e.g., material names containing *_CLOTH_* in our tutorial asset; select all if multiple slots exist).
  5. Click "Generate Separated Mesh Prefab" to export the isolated Base Outfit Prefab.
  6. Perform the same separation process for the target body avatar to create the target clothing prefab.
Figure 5: Selecting clothing material slots (*_CLOTH_*) in Mesh Separation to export isolated outfit prefabs

Step 2: Launch Outfit Builder & Set References

  1. Open Tools > zgock > ShapeSync > Outfit Builder.
  2. Figure Root: Assign the root GameObject of the Figure Prefab created in Guide 1.
  3. Figure Animator: Assign the Figure's Animator component.
  4. Base Outfit Root: Assign the root GameObject of the isolated Base Outfit Prefab from Step 1.
  5. Registry Id: Enter a unique identifier for the outfit (e.g., shirt-1).
  6. Registry Name: Enter a human-readable descriptive name (e.g., White Shirt).

Step 3: Add FBM Targets & Build

  1. Click "Add FBM Target" under the FBM Outfit Roots section.
  2. Enter the matching Figure FBM name (BasicGirl) and assign the extracted target clothing prefab.
  3. Click "Generate Skinned Mesh Outfit Prefab" to export the final ShapeSync Outfit Prefab (e.g., Shirt_ShapeSyncOutfit.prefab).
Figure 6: Configuring Figure Root, Base Outfit Root, Registry Id / Name, and FBM Target in Outfit Builder

5. Practical Guide 3: Scripting Control (Runtime API)

Control FBM weights dynamically and perform safe Outfit attachment (TryAttach) and detachment (Detach) at runtime via C# scripting.

using UnityEngine;
using zgock.ShapeSync;

/// <summary>
/// Example script demonstrating ShapeSync Runtime API (OutfitAttacher / DynamicBoneBlender) control.
/// </summary>
public class ShapeSyncRuntimeController : MonoBehaviour
{
    [Header("Target References")]
    [SerializeField] private DynamicBoneBlender dynamicBoneBlender;
    [SerializeField] private OutfitAttacher outfitAttacher;

    [Header("Outfit Prefab to Attach")]
    [SerializeField] private ShapeSyncOutfit outfitPrefab; // e.g., ShapeSyncOutfit component attached to Shirt_ShapeSyncOutfit Prefab

    // Store attached Registry ID to ensure safe detachment
    private string attachedRegistryId;

    private void Start()
    {
        if (dynamicBoneBlender == null) dynamicBoneBlender = GetComponent<DynamicBoneBlender>();
        if (outfitAttacher == null) outfitAttacher = GetComponent<OutfitAttacher>();
    }

    /// <summary>
    /// Updates the target FBM (Body Morph) weight.
    /// </summary>
    /// <param name="targetIndex">Index of the target FBM in the blender.</param>
    /// <param name="weight">Deformation weight (0.0f to 1.0f).</param>
    public void SetBodyMorphWeight(int targetIndex, float weight)
    {
        if (dynamicBoneBlender == null || dynamicBoneBlender.Targets == null) return;

        if (targetIndex >= 0 && targetIndex < dynamicBoneBlender.Targets.Count)
        {
            // Update weight for the specified FBM target
            dynamicBoneBlender.Targets[targetIndex].weight = Mathf.Clamp01(weight);
        }
    }

    /// <summary>
    /// Dynamically attaches an Outfit prefab at runtime.
    /// </summary>
    public void AttachOutfit()
    {
        if (outfitAttacher == null || outfitPrefab == null) return;

        // Attempt to attach the Outfit prefab containing ShapeSyncOutfit component
        bool success = outfitAttacher.TryAttach(outfitPrefab);
        if (success)
        {
            // Store the RegistryId upon successful attach to guarantee accurate detachment
            attachedRegistryId = outfitPrefab.RegistryId;
            Debug.Log($"Outfit attached successfully. Registry ID: {attachedRegistryId}");
        }
        else
        {
            Debug.LogWarning($"Failed to attach outfit: {outfitPrefab.name}");
        }
    }

    /// <summary>
    /// Detaches the currently attached Outfit using its stored Registry ID.
    /// </summary>
    public void DetachOutfit()
    {
        if (outfitAttacher == null || string.IsNullOrEmpty(attachedRegistryId)) return;

        // Attempt to detach using the stored Registry ID
        bool success = outfitAttacher.Detach(attachedRegistryId);
        if (success)
        {
            Debug.Log($"Outfit detached successfully. Registry ID: {attachedRegistryId}");
            attachedRegistryId = null;
        }
        else
        {
            Debug.LogWarning($"Failed to detach outfit. Registry ID: {attachedRegistryId}");
        }
    }
}

6. Troubleshooting & Prerequisites

If you encounter issues during execution, check the following mandatory prerequisites:

  • Humanoid Avatar Verification:
    • Ensure Rig type is set to Humanoid in Model Import Settings for both Base and Target models.
  • Topology Identical Requirement:
    • Verify that Base and Target meshes share identical vertex counts and topology. Differing mesh topologies will result in build errors.
  • Animator Controller & Clip Assignment:
    • If motion fails to play in Play mode, confirm that a valid Controller and Animation Clip are assigned to the Animator.
  • FBM Target Selection:
    • Confirm that your script or Inspector selection targets the active Figure GameObject carrying DynamicBoneBlender.
