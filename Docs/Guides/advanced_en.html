ShapeSync Advanced Features Guide

This document serves as Chapter 2 of the guide for ShapeSync, a Unity middleware for 3D avatar dressing and body deformation. Building upon the foundational Figure setup and Full Body Morph (FBM) controls learned in tutorial_en.html, this guide covers advanced workflows: Partial Body Morphs (PBM), Bone Correction Profiles (BC Profile), Profile Controlled Morphs (PCM), and Surface Fit projection.

1. Overview & Feature Matrix

While basic Full Body Morphs (FBM) conform clothing to overall body shape changes, ShapeSync provides three advanced features for localized deformations, bone pose corrections for specialized footwear (e.g., high heels/platform shoes), and body mesh anti-clipping controls.

All of these settings (BC Profile, PBM, PCM, etc.) are automatically applied and synchronized to the Figure at runtime by ShapeSync's internal attachment mechanism.

Feature Target Binding Tools / Components Purpose & Effect
Partial Body Morph (PBM) Both Figure & Outfit PBM Baker
(Tools > zgock > ShapeSync > PBM Baker)		 Bakes localized body morphs (e.g., chest or waist adjustments) into existing Figure / Outfit prefabs.
Bone Correction Profile (BC Profile) Outfit Side BC Profile Builder
(Tools > zgock > ShapeSync > BC Profile Builder)		 Corrects Humanoid bone poses/scales on the Figure when wearing specific outfits (e.g., tiptoe stance for heels).
Profile Controlled Morph (PCM) Outfit Side Figure PCM Builder
(Tools > zgock > ShapeSync > Figure PCM Builder)		 Automatically applies forced morphs onto the Figure mesh to prevent body mesh penetration/clipping through clothes.
Surface Fit (Surface Projection) PCM Generation Option Figure PCM Builder
(Surface Fit Tab / Optional)		 Builds PCM targets via surface projection when the target pose mesh has a different topology from the Figure.

2. Partial Body Morph (PBM) Integration & Synchronization

Partial Body Morphing (PBM) applies localized body shape modifications (such as BreastSize) independently of global FBM body shape changes, deforming both Figure and Outfit in sync. Instead of building via Figure Builder or Outfit Builder, PBMs are baked directly into existing Figure and Outfit assets using the PBM Baker editor tool.

Step 1: Preparing Mesh Assets for PBM

Prepare the following mesh assets (all present as GameObjects in the Scene) required for baking PBMs:

  • Assets for Figure:
    • Source Figure / Outfit: Existing Figure object created in Chapter 1
    • Source Renderer: Figure base shape SkinnedMeshRenderer
    • Base PBM Renderer: BasicFemaleBreastSize (Chest adjustment mesh Renderer in base FBM state)
    • Target Renderer: BasicGirlBreastSize (Chest adjustment mesh Renderer in target FBM state)
  • Assets for Outfit:
    • Source Figure / Outfit: Existing Outfit object created in Chapter 1
    • Source Renderer: Outfit base shape SkinnedMeshRenderer
    • Base PBM Renderer: BasicFemaleShirt2BreastSize (Outfit chest adjustment mesh Renderer in base FBM state)
    • Target Renderer: BasicGirlBreastSize (Outfit chest adjustment mesh Renderer in target FBM state)

Step 2: Baking PBM into Figure using PBM Baker

  1. Open Tools > zgock > ShapeSync > PBM Baker from the menu bar.
  2. Set Mode to Figure.
  3. Assign Source Figure / Outfit to your Scene's Figure object.
  4. Assign Source Renderer to the Figure's base SkinnedMeshRenderer.
  5. Assign Base PBM Renderer to BasicFemaleBreastSize's SkinnedMeshRenderer.
  6. Set PBM Name to "BreastSize".
  7. In the FBM Target Renderers section, click "Generate Target Entries" or "Add FBM Target".
  8. For the newly added target item, set FBM Name to BasicGirl and assign Target Renderer to BasicGirlBreastSize's SkinnedMeshRenderer.
  9. Click "Bake PBM Output Prefab" at the bottom of the window to generate a Figure Prefab baked with PBM (BreastSize).

Step 3: Baking PBM into Outfit using PBM Baker

  1. Open Tools > zgock > ShapeSync > PBM Baker again.
  2. Set Mode to Outfit.
  3. Assign Source Figure / Outfit to your Scene's Outfit object.
  4. Assign Source Renderer to the Outfit's base SkinnedMeshRenderer.
  5. Assign Base PBM Renderer to BasicFemaleShirt2BreastSize's SkinnedMeshRenderer.
  6. Set PBM Name to "BreastSize" (matching the Figure side).
  7. In the FBM Target Renderers section, click "Generate Target Entries" or "Add FBM Target".
  8. Set FBM Name to BasicGirl and assign Target Renderer to BasicGirlBreastSize's SkinnedMeshRenderer.
  9. Click "Bake PBM Output Prefab" at the bottom to generate an Outfit Prefab baked with PBM (BreastSize).
Figure 1: PBM Baker GUI (Figure / Outfit Mode Settings)

Step 4: Scene Attachment & Real-time PBM Synchronization Testing

  1. Place the PBM-baked Figure Prefab in the Scene and attach the PBM-baked Outfit in Play mode.
  2. Select the Figure in the Hierarchy and inspect its DynamicBoneBlender (DBB) component in the Inspector.
  3. Verify Target Entry Addition: Confirm that a new target entry named PBM_BreastSize automatically appears under DBB's Targets list.
  4. Test Morph Deformation: Adjust the weight slider for the newly added PBM_BreastSize entry.
  5. Success Criterion: Verify that both Figure (body) and Outfit (clothing) chest meshes deform synchronously and seamlessly as the slider moves.
Figure 2: Real-time Synchronized Deformation with PBM_BreastSize Slider in DynamicBoneBlender

3. Shoe Attachment & Pose Misalignment: BC Profile (BCP) Introduction

Using footwear attachment (e.g., platform shoes or high heels) as an example, this section demonstrates why Bone Correction Profiles (BC Profile) are required and how to capture and apply them.

Step 1: Creating Shoe Prefab and Discovering Misalignment

  1. Decompose BasicFemale / BasicFemaleShoes1 using the Mesh Separation tab in Mesh Utility to create a Shoes1 Prefab.
  2. Attach the shoe Prefab to the Figure in the Scene.
  3. Problem Discovery: Notice that the shoe's position and orientation are severely misaligned relative to the Figure's feet.
Figure 3: Initial Misalignment of Shoe Attachment (Pose Difference)

Step 2: Identifying Root Cause (Pose Misalignment) & Role of BC Profile

  1. Extract the shoe's reference body mesh using Mesh Separation, place it in the Scene, and align its transform with the Figure.
  2. Root Cause Identified: The shoe asset was modeled for a "tiptoe" stance rather than the Figure's default rest pose. To fit the shoe, the Figure's foot bones need a slight tiptoe pose correction.
  3. Role of BC Profile: BC Profile (Bone Correction Profile) is required to automatically apply this Humanoid bone rotation and position correction upon clothing attachment.
Figure 4: Extracting Body Mesh with Separator and Comparing Foot Poses

Step 3: Capturing Profiles with BC Profile Builder

  1. Do not alter the original Base Figure; duplicate the Base Figure in the Hierarchy.
  2. On the duplicated Base Figure, adjust the Hip Y position and Foot X rotation manually to create the tiptoe stance matching the shoe.
  3. Open Tools > zgock > ShapeSync > BC Profile Builder from the menu bar.
  4. Configure the window reference fields as follows:
    • Base Figure Root: Assign the original Base Figure object (unmodified rest pose).
    • Current Pose Figure Root: Assign the duplicated Base Figure object (with manual tiptoe pose).
  5. Click "Capture Current Pose as Profile".
  6. The Humanoid bone transform differences (TRS) between rest pose and tiptoe pose are captured and saved as a `ShapeSyncHumanoidBoneCorrectionProfile` asset (BasicFemale_BCProfile).
  7. Repeat the same capture process for BasicGirl (duplicate, adjust pose, capture) to save `BasicGirl_BCProfile`.
Figure 5: BC Profile Builder GUI Setup (Step 3-4)

Step 4: Rebuilding in Outfit Builder and Discovering Penetration

  1. Open Tools > zgock > ShapeSync > Outfit Builder from the menu bar.
  2. Set the required fields:
    • Figure Root: Figure Prefab root GameObject
    • Figure Animator: Figure `Animator` component
    • Base Outfit Root: Extracted Base shoe Prefab root GameObject
    • Registry Id: shoes-1
    • Registry Name: Shoes1
    • Base Outfit BC Profile (Optional): Assign BasicFemale_BCProfile created in Step 3
  3. In the FBM Outfit Roots section, add the target entry (BasicGirl) and assign BasicGirl_BCProfile to its BC Profile field.
  4. Click "Generate SkinnedMesh Outfit Prefab" to export the shoe Prefab with BC Profile embedded.
  5. New Problem Discovery (Mesh Penetration):
    • Attach the newly generated shoe Prefab to the Figure in the Scene.
    • The foot angles and heights now match perfectly, but the sole and sides of the foot mesh penetrate (clip through) the shoe.
Figure 6: Footwear Attachment after BCP and Mesh Penetration (Clipping) Issue

4. Eliminating Clipping: PCM & Surface Fit

Step 1: The Necessity of Profile Controlled Morph (PCM)

  1. The mesh clipping discovered in Section 3 Step 4 cannot be resolved by bone pose adjustments (BCP) alone.
  2. Comparing the shoe-fitting body mesh with the Figure reveals that the foot sole and sides need to be slightly contracted (indented).
  3. To prevent body mesh penetration through clothing, Profile Controlled Morph (PCM) is required to dynamically depress/contract Figure mesh areas when wearing specific outfits.

Step 2: Two-Stage Target Generation in Figure PCM Builder

Building a PCM Payload with Figure PCM Builder follows a mandatory Two-Stage workflow.

  1. Open Tools > zgock > ShapeSync > Figure PCM Builder from the menu bar.
  2. Configure basic fields:
    • Source Figure Root: Figure root GameObject
    • Source Renderer: Figure base shape SkinnedMeshRenderer
    • Outfit Name: Shoes1

Stage 1: Generating Same-Topology Target Prefabs

Generate same-topology target prefabs for Base and FBM Targets using BC Profiles and optional Surface Fit Targets.

  1. Set Base BC Profile to BasicFemale_BCProfile and Base Surface Fit Target (optional) to the shoe-wearing body mesh SkinnedMeshRenderer.
  2. Click "Generate Base Target from BC Profile" and save the generated same-topology Target Prefab (e.g., BasicFemale_Shoes1_BaseTarget.prefab).
  3. In the FBM Target SkinnedMeshes section, click "Add FBM Target", set FBM Name to BasicGirl, Target BC Profile to BasicGirl_BCProfile, and Surface Fit Target (optional) to BasicGirl's shoe-wearing body mesh Renderer.
  4. Click "Generate Target from BC Profile" and save the generated target Prefab (e.g., BasicGirl_Shoes1_Target.prefab).
Figure 7: Stage 1 Figure PCM Builder GUI (Generating Same-Topology Target Prefabs)

Stage 2: Assigning Target Renderers and Exporting PCM Payload

Assign the `SkinnedMeshRenderer`s from Stage 1's generated target prefabs to `Base Target Renderer` and each `Target Renderer` entry to build the final PCM Payload.

  1. Assign Stage 1's generated Prefabs' `SkinnedMeshRenderer`s to mandatory fields `Base Target Renderer` and each target entry's `Target Renderer`.
  2. Click "Generate Figure PCM Prefab" at the very bottom of the window.
  3. A Plugable PCM Payload (`ProfileControlledMorphAsset`) incorporating surface projection will be exported and saved.
Figure 8: Stage 2 Figure PCM Builder GUI (Assigning Target Renderers and Generating PCM Payload)

Step 3: Final Assembly in Outfit Builder & Runtime Verification

  1. Open Tools > zgock > ShapeSync > Outfit Builder from the menu bar.
  2. Set and verify each field:
    • Figure Root: Figure Prefab root GameObject
    • Figure Animator: Figure `Animator` component
    • Base Outfit Root: Extracted Base shoe Prefab root GameObject
    • Registry Id: shoes-1
    • Registry Name: Shoes1
    • Base Outfit BC Profile (Optional): BasicFemale_BCProfile
    • Plugable PCM Payload (optional): Assign Step 2's generated PCM Payload (`ProfileControlledMorphAsset`)
  3. In the FBM Outfit Roots section, verify `BasicGirl` target reference and BC Profile (`BasicGirl_BCProfile`) assignment.
  4. Click "Generate SkinnedMesh Outfit Prefab" to build the final shoe Outfit Prefab.
Figure 9: Final Assembly with PCM Payload and BCP in Outfit Builder
  1. Runtime Verification (Success Criterion):
    • Attach the completed shoe Prefab to the Figure in Play mode.
    • Verify that foot angles and heights match perfectly, and that all mesh penetration/clipping along the sole and sides is completely eliminated.
Figure 10: Final Shoe Attachment Result (Perfect Fit with Pose Correction and Penetration Elimination)

5. Summary

By leveraging ShapeSync's advanced features, you can achieve sophisticated avatar customization beyond simple body morphing: bone pose corrections for specialized footwear (BC Profile), body mesh anti-clipping controls (PCM), surface projection fitting for different mesh topologies (Surface Fit), and localized body modifications (PBM).

* Note on VRM Advanced Features
VRM-specific features such as automatic SpringBone physics rebuilding and VRM Expression synchronization will be covered in detail in a separate VRM Integration Guide.
